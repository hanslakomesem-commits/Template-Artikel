Penting sebelum dipakai

Template Word asli tetap disertakan tanpa perubahan. Versi .doc tersedia pula dalam bentuk konversi .docx untuk keperluan pemrosesan browser. Sistem menjaga isi dan objek artikel asli, tetapi pengaturan layout setelah diproses dapat mengubah pembagian halaman. Jika jurnal membutuhkan kesesuaian penuh, edit artikel langsung pada template DOCX aslinya menggunakan Microsoft Word.

PDF dapat dibuat melalui fitur Save As PDF di Word/LibreOffice setelah mengecek tata letak. Tidak ada tombol PDF otomatis agar aplikasi tidak memberi hasil PDF yang berpotensi berbeda dari Word.
