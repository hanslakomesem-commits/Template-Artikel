# Pemetaan template Rabbani

Referensi: template.docx asli, diperiksa halaman 1–4, termasuk properti Word dan hasil render.

| Bagian | Tata letak |
|---|---|
| Kertas | A4, margin 3 cm, jarak header/footer sekitar 1,25 cm |
| Halaman pertama | Identitas jurnal, ISSN, edisi, URL di kiri; logo kanan |
| Judul | Book Antiqua 13 pt, tebal, tengah, spasi 1,5 |
| Penulis | 11 pt tebal, tengah |
| Afiliasi dan email | 10 pt tebal, tengah |
| Kontak WA | 12 pt, tengah, sebelum panel abstrak |
| Abstrak | ABSTRACT kemudian ABSTRAK; 11 pt, spasi tunggal, rata kiri-kanan; panel kiri sekitar 9,4 cm |
| Sidebar | ARTICLE HISTORY: Received, Revised, Accepted; KEYWORDS di bawahnya; bingkai sendiri di kanan |
| Isi | 12 pt, spasi 1,5, rata kiri-kanan, inden baris pertama 1,5 cm |
| Halaman 2 dan genap berikutnya | Penulis/judul pendek/DOI kiri, logo kanan; nomor halaman di awal footer kiri |
| Halaman 3 dan ganjil berikutnya | Logo kiri, penulis/judul pendek/DOI kanan; nomor halaman di akhir footer kanan |
| Footer pertama | Hak cipta, tanggal editorial, rentang halaman; nomor halaman di kanan |
| Tabel dan gambar | Tabel dengan judul di atas, gambar dengan keterangan di bawah pada contoh; objek sumber dipertahankan |
| Catatan kaki | Catatan kaki Word di bawah teks utama, terpisah dari footer penerbitan |
| Daftar pustaka | Spasi tunggal, inden menggantung 1 cm; kategori Buku / Artikel Dalam Jurnal bergaris bawah bila tersedia |
| Halaman terakhir | Mengikuti paritas halaman biasa; bukan footer khusus |

Isi contoh template lebih pendek daripada artikel pengguna. Posisi awal pendahuluan dan jumlah halaman mengikuti panjang teks; aplikasi tidak memangkas abstrak atau isi untuk memaksakan empat halaman. Panel menggunakan aliran tabel, bukan kotak teks tinggi tetap yang dapat menyembunyikan teks. Warna panel rata biru muda, bukan gradasi.

Metadata publikasi tidak boleh berasal dari nama, tanggal atau DOI contoh. Kolom opsional web diteruskan sebagai JSON `metadata` ke API. Data kosong memakai tanda —. `running_title` mengatur judul pendek header; judul utama tetap utuh.

Pemroses mempertahankan objek dan catatan kaki asli, tetapi tidak menulis ulang sitasi, mengklasifikasikan referensi otomatis, atau mengubah struktur ilmiah. Penempatan caption sumber tetap perlu diperiksa bila sumber tidak mengikuti struktur contoh.
